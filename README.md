# CryptoEdge — Market Terminal

Institutional-grade crypto market intelligence dashboard. Real-time price data, volatility metrics, and market structure analysis for quantitative trading decisions.

## Features

- Dark terminal aesthetic (DM Mono + Outfit + Syne fonts)
- Real-time market data visualization
- Chart.js-powered interactive charts
- Designed for quant/algorithmic trading workflows

## Tech

- HTML/CSS/JS (single-page)
- Chart.js 4.x
